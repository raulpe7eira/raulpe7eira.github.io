This project holds the contents for my personal website, hosted at <https://raulpe7eira.tech>.

Static site served by GitHub Pages from `docs/`. The HTML pages are generated by a small Elixir app (`mix site.build`); the site itself is plain HTML, CSS and JavaScript, with no frontend framework or bundler.

## Development

Requires Erlang/OTP and Elixir as pinned in `mise.toml` (`mise install`).

```sh
mix deps.get
mix site.build    # render the pages into docs/
mix precommit     # compile with warnings as errors, format, credo, deps audit, tests with coverage
```

Preview with any static server rooted at `docs/`, e.g. `python3 -m http.server -d docs 8000`.

| Path | What it is |
| --- | --- |
| `lib/`, `priv/templates/` | generator code and EEx templates |
| `test/` | ExUnit tests |
| `docs/` | published site; HTML pages here are generated, don't edit them by hand |
| `docs/assets/`, `docs/images/` | CSS, JS and images, edited directly |

CI (GitHub Actions) runs the same checks, posts coverage to Coveralls (minimum 90%) and fails if `mix site.build` changes anything in `docs/`. Dependabot keeps Mix deps and GitHub Actions up to date.
